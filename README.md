# Varionica Craft Brewery

Jednostranična prezentacijska web stranica za **Varionica craft brewery** iz Pisarovine (craft pivovara od 2014.).

**Live:** https://kriscro99.github.io/varionica/

- Čisti HTML / CSS / JS, bez build koraka (`index.html`, `css/style.css`, `js/main.js`)
- Logo vektoriziran iz originalne slike (`img/logo.svg`)
- Podaci o pivima u `js/main.js` (`BEERS` i `LAB`)
- Fotografije s Facebook stranice pivovare i arhive varionica.com

Lokalno: `python3 -m http.server` pa otvori `http://localhost:8000`.
